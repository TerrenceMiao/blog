Setting up 3x-ui server at home internet on IPv6 without dedicated VPS

2026-08-27 Guestbook

Home internet with Native IPv6 on. Enable IPv6 on NBN provider at first, then test IPv6 by visiting https://test-ipv6.com/ or https://ipv6test.google.com/, checking IP info at https://ifconfig.co/.

Register your account at ClouDNS https://www.cloudns.net/ and receive a FREE DNS domain e.g. igloo-proxy.cloud-ip.cc. Then add a AAAA type DNS record points to your x3-ui https://github.com/MHSanaei/3x-ui server’s IPv6:
